# VERITE dataset integrity and provenance

**FULL authorized local image evaluation.** The user confirmed university Hugging Face access. No credentials were inspected or exposed, and no gated download, publisher scraping or image redistribution occurred. The 65,287,817-byte local archive exactly matches the public release LFS SHA-256 `e9e3c7237d19ce42e288408461b4d480717bf818b1488c28052d32d60cbc05e5` at revision `858e30eb4416402634d9397e72da5fe8af959f96`. Local CSV exactly matches the official repository file, SHA-256 `7f5661860f2e34624c1721710ed37fac5e1e78a4307400530dd587cb0d15a040`, commit `74adfa1c8e13a027bfc1146c775958e832bd1089`. Public provenance requests/receipts are recorded in `provenance_initial.json`; the raw official inputs remain under `data/external/verite/`.

The pinned current official CSV has **1,001** rows: true 338, miscaptioned 338, out-of-context 325. Earlier paper/README and the old unexecuted adapter expected 1,000 (324 out-of-context). We used the current official bytes verbatim; no record was trimmed or annotation silently corrected. This version difference matters when comparing published results. Prior access-blocked reports remain historical records and have not been overwritten.

ZIP structure was inspected first: 665 entries (one directory, 664 images). All 664 images decoded. The annotations reference 663 unique files, with 338 repeated image references; all 1,001 image-caption records are complete. Missing/invalid referenced images: 0. Exact annotation/provenance mismatches: 0. `images/false_179.jpeg` is an extra unreferenced archive member and was not substituted for any annotation path. Every extracted image has a file hash, decoded RGB pixel hash, dimensions and CRC record. Traversal, noncanonical paths, case collisions, symlinks, encrypted entries and excessive expansion are rejected.

Verified paired links: 338 true–miscaptioned (shared image), 325 true–out-of-context (shared exact caption); 338 original families. Joining shared captions, images/pixels and article URLs yields 336 components. Sources: 771 Snopes rows and 230 Reuters rows. All 1,001 records join author article metadata. There are 675 unique exact captions and 326 repeated caption rows. No retained Fakeddit text, byte-hash or pixel-hash overlap was found; this does not rule out related events, near duplicates or pretraining exposure.

The [official research repository](https://github.com/stevejpapad/image-text-verification) provides annotation/structure provenance. The [authorized image release](https://huggingface.co/datasets/stefpapad/VERITE) is for research and prohibits redistribution. Images, full caption manifests, private failure-case joins and embeddings remain in local restricted-data folders and are excluded from the deliverable package. Public aggregate reports and code contain no credentials or image bytes.
