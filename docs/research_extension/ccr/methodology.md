# CCR method and implementation notes

The architecture is two frozen-feature classifiers, A and B, followed by a small selector. A uses BERT768 and ResNet502048. B adds one standardized CLIP-B/32 cosine. Historical final head weights stay fixed. The selector must compute both A and B at inference; this method does not save the CLIP encoder computation and has no compute-saving claim.

For real-class probability `p`, binary cross-entropy is `−y log(p) − (1−y) log(1−p)`, clipping probabilities at1e−6. The OOF utility target is `CE(A,y) − CE(B,y)`. Positive values favor B. Equivalently, utility is `y log(p_B/p_A) + (1−y) log((1−p_B)/(1−p_A))`. Consequently this is a comparison of conditional predictive losses of two fitted models; it is not a causal estimate or a factual truth test.

The feature allowlist is enforced by a function that accepts only `p_a`, `p_b` and `cosine`. Its10 outputs are the two probabilities, their log-odds, log-odds difference, absolute class margins, entropies and cosine. Labels, subreddit, six-way category, family, text, and IDs cannot be arguments to this function. IDs serve only saved-row alignment, fold grouping and random-control seeding.

Five label-blind SHA256 family folds cover every training row exactly once per classifier seed. Each fold's other rows supply a deterministic10% internal stopping split; only the remaining rows fit normalization and gradients. Checkpoints preserve optimizer/order RNG/Torch RNG for epoch-level restart. Heads use the original128-unit architecture, dropout0.3, AdamW, batch128, max40 epochs and patience7. Selection uses internal validation Macro-F1 with loss tie-break. The model predicts its held-out fold only after selection.

The gate fits OOF targets from50,000 rows. Ridge alpha100 with input standardization is primary; intercept mean and a depth3 tree/minimum500 rows per leaf are fixed ablations. No nested model selection is needed because no hyperparameter/model-family search is performed. Three classifier seeds receive separate gate fits and thresholds. The utility gate's in-sample fit to OOF-derived targets is not itself an unbiased gate-evaluation set.

Existing final A/B heads produce validation predictions. Validation chooses thresholds from OOF-score quantiles and fixed endpoints and fits separate temperature baselines. Ridge's validation loss CI guard determines whether operational CCR follows ridge or always B. The candidate is still reported if the guard fails. Because thresholds and the original heads were validation-selected, the guard is an operational heuristic with selection bias, not an independent confidence guarantee. All test predictions occur after policy and source hashes are frozen.

Fakeddit class0 is fake and class1 real. A probability exactly0.5 predicts class0, matching the historical argmax tie convention. Brier is `(p_real−y)^2`. ECE is confidence calibration, not real-class probability calibration. Subgroup accuracy intervals are Wilson row intervals; paired subgroup delta intervals use an explicitly labeled normal approximation and are unreliable for tiny/correlated slices. Overall paired proper-loss/Macro-F1/accuracy intervals use5,000 common-index bootstraps. Known Fakeddit family clusters are singletons; broader event correlation is not resolved.

Before scientific training,16 tests checked group isolation, held-label perturbation invariance of gradient training and stopping, scaler fit isolation, predictor allowlist, probability clipping, threshold ties, exact fallback, metric conventions, bootstrap cluster units and provenance tampering. A400-training-row/two-fold/two-epoch smoke run used a separate namespace and did not evaluate either test set. The Windows sandbox's default temporary location initially denied file writes; tests were moved to an explicitly resolved CCR scratch directory and passed. No training rule changed in that fix.

External support expects an already authorized local official `VERITE.csv` and image directory. It verifies the full official population and metadata, extracts the same cached frozen encoders, links article/caption/image components for bootstrap, and uses the previously frozen policy. This adapter has not been exercised with real VERITE images because access is unavailable. Such a future run must remain a cross-task/domain-transfer test, and its images must never enter the distributable report package.
