# NewsCLIPpings preflight — PARTIAL

The complete Path B blueprint was read before this implementation. A pre-change SHA-256 inventory covers 59,067 files (5,281,495,316 bytes), including original, BRAS and CCR artifacts. Original A/B and BRAS heads were inspected with PyTorch weights-only loading; the normalizer shapes/finiteness and existing bank receipt were verified. CCR's three policies have guard=false and B fraction=1. No retraining is planned.

Official metadata is public at [the author-hosted release](https://huggingface.co/g-luo/news-clippings/tree/main), pinned here to `a2bbe9a8125f47a5c26338125c71e05be0266cf7`. Six annotation files totaling approximately 11.8 MB were retrieved and their hashes recorded. The four strategy files are used for membership audit only, never appended/double-counted. The author-hosted CLIP test embeddings are 105,640,860 + 86,368,983 bytes. Supplementary test metadata is 37,369,991 bytes. These selected assets fit the available 98.2 GiB of disk space. No training embeddings, trained author models or whole repository clone is needed.

[Official VisualNews](https://github.com/FuxiaoLiu/VisualNews-Repository) links to the [Rice landing page](https://www.cs.rice.edu/~vo9/visualnews/). Observed HEAD for `origin/data.json`: HTTP 404. HEAD for `origin.tar`: HTTP 200, 97,916,641,280 bytes (91.19 GiB). A bounded 4,096-byte request returned HTTP 206 and a valid tar header. This establishes archive availability, not selected image availability. No full archive is requested. The archive does not expose a per-image offset index in the landing page; further limited availability probes are recorded separately.

The HF card declares Apache-2.0. This label is not treated as a blanket license to redistribute underlying newswire/publisher images. Only the official research release or user-authorized local copies are eligible; no publisher scraping, gated access bypass, terms acceptance or image redistribution. Raw assets stay under `data/external/newsclippings/` outside the deliverable package.

The [NewsCLIPpings paper](https://aclanthology.org/2021.emnlp-main.545/) describes automatically repurposed images. Its labels indicate original versus generated mismatched pairing, not independently fact-checked news. CLIP helped construct/filter the dataset. The [official code/data instructions](https://github.com/g-luo/news_clippings) identify ViT-B/32 embeddings but do not establish equality to this project's pinned extraction contract. Official-embedding analysis must remain a separate score-only provenance evaluation. Pinned cosine/BRAS and frozen A/B inference require verified selected images and captions.

Exact requests/status/size/hash records: `results/external_eval/newsclippings/data_access.json`. Existing-model shapes and hashes: `existing_project_audit.json`. No shared package versions changed. No test performance computed during preflight.
