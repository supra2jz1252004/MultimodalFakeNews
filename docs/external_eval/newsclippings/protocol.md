# Locked protocol

The SHA-linked machine protocol is `results/external_eval/newsclippings/protocol.json` (SHA-256 `d2cb3b5369573567317dac3327c0217406a1359ee6b4ff261d42df6845c96acc`). It was written before any external test metrics. Analysis code was hash-frozen before score generation. Selection uses SHA256(seed NUL pair-ID), seed 20261108, within four strategies. Fixed 100-group smoke (25 per strategy); fixed main 1,000 groups (250 per strategy), nested smoke, no availability/performance replacements. The official merged test population is 3,632 groups, 908 per strategy. The selection therefore preserves its equal strategy allocation.

The primary planned comparison is pinned BRAS mean `(m_text+m_image)/2` minus pinned cosine in within-group ranking. k=16 and the existing 4,096-entry Fakeddit training bank remain unchanged. Directional comparisons are secondary. **This planned comparison was not executed:** official embedding provenance is not verified identical to the pinned bank contract. Only the separately declared official CLIP score-only baseline was executed. No new comparator, threshold, classifier or adaptive weights were introduced after test inspection.

Higher scores predict pristine pairing. Exact ties receive half credit; strict and 1e-6 tolerance outcomes are robustness checks. ROC-AUC and average precision use pristine as positive. Paired margin is score(pristine) minus score(mismatch). Bootstrap: 5,000 common-component resamples, seed 20261108, percentile 95% intervals. Components link shared caption/image IDs across roles, normalized captions, known article paths, and available byte/pixel hashes. Missing image hashes remain unknown. In this run there are 921 linked components for 1,000 groups (953 before article/caption links). These are observed-dependence units, not a guarantee of independent events.

Two-sided cluster sign flips use seed 20261109 and 10,000 draws; +1 correction. Secondary score comparisons and construction-strategy tests form a Holm-corrected family. Transfer tests across three classifier seeds form a separate Holm family and would not treat seeds as extra independent examples. No threshold is needed and no external adaptation was performed. Failure cases are the fixed ten smallest and ten largest cosine margins, explicitly exploratory. Protocol clarification: actual `similarity_score` fields are numeric generation scores; strategy is read from `source_dataset`, not inferred from this number.
